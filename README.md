# DAA Assignment 3 — Graph Algorithms

Design and Analysis of Algorithms  
Assignment 3: DSU, MST, SCC and Shortest Paths

## Project Overview

This project implements and benchmarks graph algorithms using Java 25, Maven and JUnit 5.

### Main Algorithms

- Disjoint Set Union (DSU) with path compression and union by size
- Kruskal's Minimum Spanning Tree
- Prim's Minimum Spanning Tree
- Kosaraju's Strongly Connected Components
- Kahn's Topological Sorting
- Shortest Paths in Directed Acyclic Graphs

### Bonus Features (+15%)

- Tarjan's SCC Algorithm (+10%)
- Condensation Graph and Critical Path (+5%)

## Requirements

- Java 25
- Maven
- Python 3
- Matplotlib (for generating plots)

## Build

From the project root:

```bash
mvn clean package
```

Alternatively, use IntelliJ IDEA:

Maven → Lifecycle → clean → package

## Run Tests

```bash
mvn test
```

Or in IntelliJ IDEA:

Maven → Lifecycle → test

JUnit 5 tests cover DSU, MST, SCC, topological sorting, DAG shortest paths, file input and reference values.

## Run Benchmark

Run the Java class:

```text
benchmark.Benchmark
```

In IntelliJ IDEA, open `Benchmark.java` and run its `main()` method.

The benchmark uses five graph sizes:

- 1,000
- 3,162
- 10,000
- 31,623
- 100,000

Each size is tested with sparse (4V) and dense (20V) graphs.

Five algorithm results are recorded for each configuration, producing 50 rows in:

```text
results/results.csv
```

Each algorithm is measured five times, and median execution time is recorded.

## Generate Plots

Install Matplotlib:

```bash
py -m pip install matplotlib
```

Run:

```bash
py scripts/plot_results.py
```

Three PNG charts are generated:

- `results/plots/operations_vs_n.png`
- `results/plots/scans_per_edge.png`
- `results/plots/kruskal_edge_share.png`

## Correctness Validation

The implementation includes:

- Comparison of Kruskal and Prim MST weights
- Comparison of Kosaraju and Tarjan SCCs
- Brute-force SCC validation
- DAG shortest paths compared with Bellman-Ford
- Stack-safety tests for 100,000 vertices
- Ten deterministic reference graph checks
- Operation counters for empirical complexity validation

All ten benchmark configurations reproduce the expected reference values.
